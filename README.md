# MelloMons — Minecraft 1.20.1 backport

This is an unofficial backport of [MelloMons](https://modrinth.com/datapack/mellomons) by MelloMatt for Minecraft 1.20.1 with Cobblemon 1.5.2. It preserves the Mew remodel, its animations, shiny texture, and the rare jungle spawn entry.

## Install

Add `MelloMons-1.20.1.zip` to the world's `datapacks` folder and also to the client's `resourcepacks` folder. Enable it in both places, then run `/reload` or restart the world.
